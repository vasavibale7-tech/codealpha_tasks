# CodeAlpha E-Commerce Store

A basic full-stack e-commerce website developed as part of the CodeAlpha Full Stack Development Internship.

## Features

- Product listings
- Product details
- Shopping cart
- User registration
- User login
- Order processing
- Product search
- SQLite database
- Backend API using Express.js

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- SQLite

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Install dependencies:

```bash
npm install
5. Start the backend server:

```bash
node server.js
```

6. Open the website in your browser.
